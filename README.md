## Instruction for installing, running and using the application

After cloning repository create on your local computer .env file on the basis of .env.example file

#### Install packages
```bash
npm install
```

#### Build application
```bash
npm run build
```

#### Run application in development mode
```bash
npm run start:dev
```

#### Run application in production mode
```bash
npm run start:prod
```
